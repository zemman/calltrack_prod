# Быстрый старт - Модуль "Инциденты / События"

## 1. Обновление базы данных

Выполните SQL скрипт для создания таблиц инцидентов:

```sql
-- Выполните в MySQL
source ../schema.sql;
```

## 2. Инициализация категорий

Запустите скрипт для создания базовых категорий инцидентов:

```bash
php init_incident_categories.php
```

## 3. Запуск системы

Откройте в браузере:
```
http://your-domain/public/
```

## 4. Доступ к модулю инцидентов

После входа в систему вы увидите новые пункты меню:
- **Инциденты** - список всех инцидентов
- **Создать инцидент** - форма создания нового инцидента
- **Категории инцидентов** (только для администраторов) - управление справочником

## 5. Основные функции

### Создание инцидента
1. Перейдите в "Создать инцидент"
2. Заполните обязательные поля: Заголовок, Описание, Дата начала, Категория
3. Нажмите "Сохранить"

### Просмотр и редактирование
1. Перейдите в "Инциденты"
2. Используйте фильтры для поиска нужных инцидентов
3. Нажмите "Открыть" для редактирования

### Экспорт данных
1. В списке инцидентов нажмите "Экспорт CSV"
2. Файл будет загружен с текущими фильтрами

## Готово!

Модуль "Инциденты / События" готов к использованию!
