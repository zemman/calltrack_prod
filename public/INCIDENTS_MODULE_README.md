# Модуль "Инциденты / События"

## Описание

Модуль "Инциденты / События" расширяет функциональность системы CallTrack, позволяя регистрировать, отслеживать и управлять инцидентами. Модуль реализован как независимый функциональный блок без внесения изменений в существующие модули.

## Установка

1. **Обновление базы данных:**
   ```sql
   -- Выполните SQL скрипт из schema.sql для создания новых таблиц
   source ../schema.sql;
   ```

2. **Инициализация категорий инцидентов:**
   ```sql
   INSERT INTO incident_categories (name, created_at, updated_at) VALUES 
   ('Техническая проблема', NOW(), NOW()),
   ('Проблема с оборудованием', NOW(), NOW()),
   ('Проблема с сетью', NOW(), NOW()),
   ('Проблема с ПО', NOW(), NOW()),
   ('Проблема с данными', NOW(), NOW()),
   ('Проблема с безопасностью', NOW(), NOW()),
   ('Проблема с производительностью', NOW(), NOW()),
   ('Проблема с доступностью', NOW(), NOW()),
   ('Другое', NOW(), NOW());
   ```

## Функциональность

### Структура инцидента

Каждый инцидент содержит следующие поля:

| Поле                  | Тип                   | Обязательность | Описание                                                                |
| --------------------- | --------------------- | -------------- | ----------------------------------------------------------------------- |
| Заголовок             | Текст                 | Обязательно    | Краткое название инцидента                                             |
| Описание              | Текст (многострочный) | Обязательно    | Подробное описание                                                     |
| Статус                | Перечисление          | Обязательно    | Открыт / Закрыт                                                        |
| Дата создания         | Дата и время          | Автозаполнение | Заполняется автоматически при создании                                |
| Дата начала           | Дата и время          | Обязательно    | Указывается пользователем                                             |
| Дата завершения       | Дата и время          | Необязательно  | Может быть пустым, если инцидент ещё не завершён                      |
| Номер INC в SO        | Текст                 | Необязательно  | Внешний идентификатор инцидента в сторонней системе                   |
| Потенциальное влияние | Текст                 | Необязательно  | Описание возможных последствий инцидента                              |
| Категория             | Справочник            | Обязательно    | Выбор из справочника «Категории инцидентов»                           |
| Оповещение в бот      | Текст                 | Необязательно  | Сообщение для отправки в чат-бот (если применимо)                     |

### Основные возможности

1. **Список инцидентов** (`index.php?page=incidents`)
   - Отображение всех инцидентов с сортировкой по статусу
   - Фильтрация по датам, категориям, статусам
   - Поиск по заголовку и описанию
   - Экспорт в CSV

2. **Создание инцидента** (`index.php?page=incident_new`)
   - Форма с валидацией обязательных полей
   - Автоматическое заполнение даты создания
   - Выбор категории из справочника

3. **Редактирование инцидента** (`index.php?page=incident_edit&id=X`)
   - Изменение всех полей инцидента
   - Возможность закрытия инцидента
   - Автоматическое заполнение даты завершения при закрытии

4. **Управление категориями** (`index.php?page=incident_categories`)
   - Добавление новых категорий
   - Редактирование существующих категорий
   - Удаление неиспользуемых категорий

5. **Экспорт данных** (`index.php?page=export_csv&type=incidents`)
   - Экспорт инцидентов в CSV с поддержкой фильтров
   - Корректное отображение кириллицы в Excel

## Навигация

Модуль интегрирован в основную навигацию системы:

- **Инциденты** - список всех инцидентов
- **Создать инцидент** - форма создания нового инцидента
- **Категории инцидентов** (только для администраторов) - управление справочником

## Технические детали

### База данных

- `incidents` - основная таблица инцидентов
- `incident_categories` - справочник категорий

### Производительность

- На странице отображаются последние 100 инцидентов
- Индексы по статусу, дате начала и дате создания
- Оптимизированные SQL запросы с JOIN'ами

## Совместимость

Модуль полностью совместим с существующей системой:
- Использует те же стили и компоненты
- Интегрирован в существующую систему авторизации
- Не изменяет существующие таблицы и функциональность
- Следует тем же принципам UX/UI

## Безопасность

- Все пользовательские данные экранируются через `Utils::h()`
- Валидация всех входных данных
- Проверка авторизации для всех операций
- Защита от SQL-инъекций через подготовленные запросы
